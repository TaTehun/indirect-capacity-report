// technical_highlights

AGGREGATION
Mode-Aware Direction
AIR and OTR aggregate past 4 weeks for trend averages. Ocean aggregates current + next 3 weeks as forward-looking capacity forecast.
DATA QUALITY
BL# Deduplication
OTR deduplicates on BL# before aggregation, keeping first occurrence. Prevents inflated load counts from multi-row entries.
RESILIENCE
All-File Validation
All three files checked upfront. Missing files collected and sent in one alert.
OUTPUT
Template-Based Excel
shutil.copy2 preserves all template formatting. Data written to mapped cells via ROW_MAP, no formula rebuilding.
DISCOVERY
Date-Driven File Lookup
Files found by glob-matching today's date (MM-DD-YY) in the filename. No hardcoded paths.
ALERTING
Typed Failure Emails
Missing file errors and runtime exceptions send distinct HTML alerts, each with relevant details.

// error_handling

Missing Tracking File
All three files checked before processing. Missing files collected and reported in one alert as a bulleted list.
Unexpected Runtime Error
Unhandled exceptions caught at top level. Alert type distinguishes missing_file from general errors.
SMTP Unavailable
If credentials fail to load, report is saved locally and a warning is logged. Run completes without email delivery.

Typed Failure Alert Email main.py 
# Missing file vs unexpected error → different body
def send_failure_alert(sender, week_num, error_msg,
                        missing_file=False):
    if missing_file:
        items = (error_msg if isinstance(
            error_msg, list) else [error_msg])
        lines = ''.join(
            f'&bull; {m}<br>' for m in items
        )
        detail = (
            f'<b>Missing File(s):</b><br>{lines}<br>'
            'Please ensure all tracking files exist.'
        )
    else:
        detail = f'<b>Unexpected Error:</b> {error_msg}'
